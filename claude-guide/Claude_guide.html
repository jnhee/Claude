Chapter 1

Claude Code 터미널 설치

Claude Code는 터미널에서 Claude와 대화하며 코딩과 파일 작업을 수행하는 CLI 도구입니다. 이 장에서는 설치부터 첫 로그인까지 다룹니다.

최종 수정 2026-11-04 · 소요 시간 약 5분 · 대상 OS: Windows, macOS, Linux

1.1사전 준비

  • 계정: Claude 구독(Pro/Max 등), Anthropic Console 계정, 또는 지원되는 클라우드 계정 중 하나
  • Windows: Git for Windows 설치 권장 (내부적으로 Git Bash 사용)
  • macOS / Linux: 별도 사전 설치 없음

1.2설치 (권장: 네이티브 설치)

사용 중인 환경에 맞는 탭을 선택해 명령어를 실행하세요.

irm https://claude.ai/install.ps1 | iex
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
curl -fsSL https://claude.ai/install.sh | bash
Note

네이티브 설치는 Node.js가 필요 없고, 백그라운드에서 자동 업데이트됩니다.

1.3다른 설치 방법

방법명령어비고
WinGet (Windows)winget install Anthropic.ClaudeCode수동 업데이트 필요
Homebrew (macOS)brew install --cask claude-code수동 업데이트 필요
npmnpm install -g @anthropic-ai/claude-codeNode.js 18 이상 필요
Warning

npm 설치 시 sudo는 사용하지 마세요. 권한 문제가 생기면 npm 전역 경로 설정을 수정하는 것이 안전합니다.

1.4설치 확인

새 터미널을 열고 아래 명령을 실행합니다. 설치 직후에는 터미널을 재시작해야 PATH가 반영됩니다.

Terminal
claude --version
claude doctor      # 설치 상태 진단

1.5첫 실행과 로그인

  1. 작업 폴더로 이동
    Terminal
    cd C:\Users\<사용자명>\Desktop\project\Claude_manual
  2. Claude 실행
    Terminal
    claude
  3. 브라우저에서 로그인 처음 실행하면 브라우저가 열리며 로그인 절차가 진행됩니다. 인증 정보는 자동으로 저장됩니다.

1.6업데이트

Terminal
claude update

증상해결 방법
claude 명령을 찾을 수 없음터미널을 완전히 닫고 다시 열기. 그래도 안 되면 설치 경로가 PATH에 있는지 확인

PowerShell 스크립트 실행 차단일반 PowerShell에서 실행하고, 필요 시 실행 정책 확인
로그인 창이 열리지 않음터미널에 표시된 URL을 직접 브라우저에 붙여넣기
설치 상태가 의심스러움claude doctor 실행

Chapter 2

필수 명령어

Claude Code를 사용하면서 꼭 알아두어야 할 슬래시 명령어, 실행 옵션, 입력 요령을 정리했습니다.

최종 수정 2026-11-04 · 소요 시간 약 5분 · 정확한 목록은 /help로 확인
Warning

명령어와 단축키는 버전에 따라 추가되거나 바뀔 수 있습니다. 동작이 다르면 /help로 현재 버전의 목록을 확인하세요.

2.1슬래시 명령어

대화창에서 /로 시작해 입력합니다.

명령용도
/help사용 가능한 명령어 목록
/clear대화 초기화. 주제를 바꿀 때 사용 (토큰 절약)
/compact대화를 요약해 컨텍스트 확보. 대화가 길어졌을 때 사용
/init프로젝트 분석 후 CLAUDE.md 생성
/resume이전 대화 이어가기
/model모델 변경
/config설정 열기
/permissions허용·차단할 도구 권한 관리
/memoryCLAUDE.md 등 메모리 파일 편집
/cost사용량 확인
/status현재 계정·모델·설정 상태 확인
/doctor설치 진단
/login, /logout계정 전환
/exit종료

2.2터미널 실행 옵션

셸(PowerShell, CMD 등)에서 claude 뒤에 붙여 사용합니다.

명령용도
claude새 대화 시작
claude -c가장 최근 대화 이어가기
claude -r이전 대화 목록에서 골라 이어가기
claude "질문"질문을 넣은 채로 시작
claude -p "질문"한 번 답하고 바로 종료 (스크립트·자동화용)
claude update업데이트

2.3대화 중 입력 요령

입력동작
@파일명특정 파일을 참조시킴. 예: @Claude_guide.html 이거 수정해줘
!명령어프롬프트에서 셸 명령을 바로 실행. 예: ! git status
#로 시작입력한 내용을 메모리에 저장 (버전에 따라 다를 수 있음)
Shift + Tab권한 모드 순환 (일반 → 자동 수락 → 계획 모드)
Esc진행 중인 작업 중단. 두 번 누르면 이전 메시지로 되돌리기
Ctrl + C입력 취소 / 종료
Shift + Enter 또는 \ + Enter줄바꿈

2.4업무에서 유용한 습관

  1. CLAUDE.md 작성 프로젝트 규칙과 자주 쓰는 지시를 적어두면 매 세션 자동으로 참고합니다.
  2. 주제가 바뀌면 /clear 대화가 길수록 정확도가 떨어지고 비용이 늘어납니다.
  3. 대화가 길어지면 /compact 중요한 맥락은 유지하면서 공간을 확보합니다.
  4. 큰 작업은 계획 모드부터 Shift + Tab으로 계획 모드에 들어가면 수정 없이 계획만 세웁니다.
  5. 어제 작업은 /resume 또는 claude -c 이전 대화를 이어서 작업할 수 있습니다.

2.5깊게 생각시키기: ultrathink

프롬프트에 ultrathink라는 단어를 넣으면 Claude가 해당 요청에서 더 오래, 더 깊게 추론하도록 유도할 수 있습니다. 복잡한 설계나 원인을 찾기 어려운 버그처럼 한 번에 풀리지 않는 문제에 적합합니다.

예시
ultrathink 이 업무 자동화 스크립트의 구조를 처음부터 다시 설계하려고 해.
현재 구조의 문제점과 개선안을 단계별로 비교해줘.
구분내용
언제 쓰나복잡한 설계, 여러 원인이 얽힌 디버깅, 장단점 비교가 필요한 의사결정
쓰지 않아도 되는 경우단순 수정, 파일 이름 변경, 짧은 질문
비용생각하는 시간이 길어지고 토큰 사용량이 늘어남
적용 범위해당 프롬프트 한 번에만 적용 (다음 요청에는 다시 입력)
Warning

추론 단계 조절 방식은 모델과 버전에 따라 다를 수 있습니다. 효과가 느껴지지 않으면 /model과 /help에서 현재 지원되는 방식을 확인하세요.

2.6곁다리 질문: /btw

Claude가 작업하는 도중에 "그런데 말이야(by the way)" 하고 짧은 질문을 던질 때 씁니다. 진행 중인 작업을 끊지 않고 빠르게 답을 받을 수 있고, 질문과 답은 본 대화의 맥락에 쌓이지 않도록 설계된 명령입니다.

Claude Code
/btw git rebase와 git merge의 차이가 뭐였지?
  • 긴 작업을 맡겨 두고 기다리는 동안 궁금한 점을 바로 물어볼 때 유용합니다.
  • 본 작업과 무관한 질문이 대화에 섞이지 않아 /clear나 /compact를 덜 써도 됩니다.
  • 가볍게 묻는 용도이므로, 파일 수정이나 명령 실행이 필요한 요청은 일반 프롬프트로 보내세요.
Note

/btw는 비교적 최근에 추가된 명령입니다. 자동 완성에 보이지 않으면 claude update로 최신 버전을 설치하세요.

2.7쉬운 설명: /eli5

ELI5는 "Explain Like I'm 5"의 약자로, 어려운 개념을 아주 쉬운 비유와 그림 같은 설명으로 풀어 주는 기능입니다. 이 환경에서는 eli5 스킬(플러그인)로 제공됩니다.

Claude Code
/eli5 API가 뭐야?
/eli5 git branch
  • 낯선 용어가 나왔을 때 개념부터 빠르게 잡고 싶을 때 사용합니다.
  • 팀원이나 비개발 직군에게 설명할 내용을 미리 쉽게 정리할 때도 좋습니다.
  • 스킬이므로 설치·활성화된 환경에서만 보입니다. /를 입력해 목록에 eli5가 있는지 확인하세요.
